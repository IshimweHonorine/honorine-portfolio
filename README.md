# Honorine Ishimwe — React Portfolio

A responsive single-page portfolio built with React, Vite, and plain CSS.

## Requirements
- Node.js 18 or newer
- npm

## Run locally
1. Extract this ZIP.
2. Open a terminal in the `honorine-portfolio` folder.
3. Install packages:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```
5. Open the local URL shown in your terminal (usually `http://localhost:5173`).

## Before publishing
- Replace the starter project cards and placeholder project preview images with screenshots and links to your real repositories.
- Confirm the degree title is exactly as written on your certificate.
- Review the CV PDF in `public/`.
- Add your LinkedIn profile URL if you want to use LinkedIn; the current link points to the general LinkedIn website.
- Do not claim WordPress experience unless you have gained it.

## Build for production
```bash
npm run build
```
The production files are generated in `dist/`.

## Publish
You can publish the built site using GitHub Pages, Netlify, or Vercel. For GitHub Pages, configure the deployment to publish the Vite `dist` folder. See the Vite documentation for deployment guidance: https://vite.dev/guide/static-deploy.html
